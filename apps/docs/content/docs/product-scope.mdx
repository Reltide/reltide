## Invited pilot

The first milestone is an evidence-backed Stripe migration draft PR for a controlled TypeScript repository on GitHub. The invited MVP also includes OpenAI. A human reviews and merges every PR.

The planned workflow connects selected repositories, establishes dependency and API-version scope, gathers official provider evidence, applies a patch in a disposable checkout, and runs independent verification. Incomplete scope, evidence, baseline, or checks hold a migration for review.

## Available today

The repository contains Next.js shells for the dashboard, website, and documentation; a Rust API with [process health](/docs/reference/generated/getHealth); a worker skeleton; and a TypeScript client generated from the Rust OpenAPI document. The local shells require no hosted credentials.

Repository installation, provider monitoring, migration orchestration, and end-to-end draft PR creation remain planned. Building this foundation does not establish that those workflows are ready.

## Platform boundaries

Rust owns business logic, authentication, authorization, webhooks, persistence, orchestration, and workers. Next.js renders UI and documentation; its search route only serves the documentation index.

Platform compute and self-hosted Temporal target Hetzner Cloud in Finland. Application PostgreSQL, Temporal and its separate PostgreSQL persistence, and ClickStack target the existing production CX23 after capacity and recovery validation. Staging is a test environment, and the dedicated management host runs Coolify. Private artifacts and off-server backups target Cloudflare R2 EU jurisdiction in the Reltide account. GitHub, provider sources, AI inference, and Resend remain external integrations. The full production stack is not yet deployed.

Read [verification](/docs/verification) and [review limits](/docs/review-limits) before evaluating a future migration draft.
