Reltide is being built to identify external API changes and prepare verified draft pull requests for engineers to review. The repository currently provides frontend shells, a Rust health API, and a generated TypeScript client. Repository onboarding and migration execution are planned.

## Start here

- [Repository permissions](/docs/repository-permissions): the planned GitHub integration.
- [Verification](/docs/verification): evidence and checks required before a draft PR.
- [Review limits](/docs/review-limits): human review and the limits of a revert.
- [API reference](/docs/reference): documentation generated from the Rust contract.

## Verification principle

Every proposed migration needs an immutable base commit, a passing baseline, provider evidence, and independent verification in a fresh checkout. A human reviews the resulting draft pull request and chooses whether to merge it.
